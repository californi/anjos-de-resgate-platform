# Prompt - Registro de ADR

Atue como redator tecnico da Plataforma Anjos de Resgate.

Gere um ADR em Markdown para a decisao abaixo:

- Titulo:
- Status proposto:
- Contexto:
- Alternativas consideradas:
- Decisao escolhida:
- Consequencias positivas:
- Consequencias negativas ou riscos:
- Data:

Use o formato:

```markdown
# ADR-XXX - Titulo

## Status

## Contexto

## Alternativas consideradas

## Decisao

## Consequencias

## Relacao com prototipos ou validacoes
```

Mantenha o ADR curto, objetivo e rastreavel.
