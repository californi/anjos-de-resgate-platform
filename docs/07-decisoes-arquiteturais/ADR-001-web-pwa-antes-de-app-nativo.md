# ADR-001 - Web/PWA antes de app nativo

## Status

Aceita.

## Contexto

A ONG precisa validar rapidamente a utilidade da plataforma e a equipe do projeto trabalhara com prototipos quinzenais.

## Decisao

Iniciar com uma aplicacao Web/PWA em vez de desenvolver aplicativos nativos para Android e iOS.

## Consequencias

- Entrega inicial mais rapida.
- Menor custo de manutencao.
- Acesso por navegador em desktop e mobile.
- Funcionalidades nativas avancadas podem exigir adaptacoes futuras.
