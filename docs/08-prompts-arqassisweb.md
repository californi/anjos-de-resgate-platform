# Prompts ArqAssisWeb

Os prompts ArqAssisWeb ficam em `/prompts` para apoiar evolucao incremental, registro de decisoes e revisao continua.

## Prompt de inclusao de modulo

Arquivo: `prompts/inclusao-modulo.md`

Uso: avaliar escopo, impacto e pontos de extensao antes de implementar um novo modulo.

## Prompt de analise continua de decisao arquitetural

Arquivo: `prompts/analise-decisao-arquitetural.md`

Uso: revisar se uma decisao continua adequada apos novas validacoes.

## Prompt de registro de ADR

Arquivo: `prompts/registro-adr.md`

Uso: gerar ADRs curtos, objetivos e rastreaveis.

## Prompt de revisao de arquitetura

Arquivo: `prompts/revisao-continua.md`

Uso: revisar acoplamento, duplicacao, responsabilidades, documentacao e riscos.
